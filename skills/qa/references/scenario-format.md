# QA 리포트 형식

Playwright 스타일의 테스트 리포트. Linear 코멘트와 메인 세션 반환용.

## 스크린샷 파일명 규칙

이슈 번호를 파일명에 포함:

```
/tmp/qa/ZEP-183-20260220-173000/
├── ZEP-183-init.png
├── ZEP-183-6-1-button.png
├── ZEP-183-6-2-modal.png
├── ZEP-183-1-2-upload-valid.png
├── ZEP-183-1-3-upload-wrongext.png
├── ZEP-183-2-2-missing-fields.png
├── ZEP-183-4-1-processing.png
├── ZEP-183-5-1-result.png
└── ...
```

패턴: `<이슈ID>-<시나리오번호>-<설명>.png`
