# QA 리포트 형식

Playwright 스타일의 테스트 리포트. **QA 폴더에 `REPORT.md`로 생성.**

## 스크린샷 파일명 규칙

이슈 번호를 파일명에 포함:

```
/tmp/qa/ZEP-183-20260220-173000/
├── REPORT.md          ← 리포트 파일 (필수)
├── ZEP-183-init.png
├── ZEP-183-0-2-modal.png
├── ZEP-183-1-2-upload-valid.png
├── ZEP-183-2-3-wrong-format.png
├── ZEP-183-4-1-processing.png
├── ZEP-183-5-1-result.png
└── ...
```

패턴: `<이슈ID>-<시나리오번호>-<설명>.png`

## REPORT.md 형식

검수 완료 후 **반드시** `$QA_DIR/REPORT.md`에 Write 도구로 생성:

```markdown
# QA 검수 리포트

**이슈**: ZEP-183 — [Admin] 일시납 결제 CSV 벌크 업로드 기능 추가
**환경**: `dev-2-admin.zep.us` | **프로필**: `zep-admin`
**일시**: 2026-02-20 17:34 | **소요**: ~3분

---

## 요약

| 구분 | 수량 |
|-----|------|
| ✅ Pass | 13 |
| ⚠️ Warning | 2 |
| ❌ Fail | 0 |
| ⏭️ Skip | 1 |
| **전체** | **16** |

---
```

## 메인 세션 반환 형식

검수 완료 후 메인 세션에 반환하는 요약 (REPORT.md와 별개):

```
QA 완료: ✅ N Pass · ⚠️ N Warning · ❌ N Fail
리포트: $QA_DIR/REPORT.md
스크린샷: $QA_DIR/
```
